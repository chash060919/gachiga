# GATIGA — 데모 지도 버전 (최종)

이 버전은 실제 GPS, 카카오맵 및 OpenStreetMap API를 사용하지 않습니다. HTML/CSS로 만든 데모 지도에 예시 마커를 표시합니다.

## 실행
`index.html`을 크롬에서 더블클릭하면 됩니다. 서버, API 키, 인터넷 연결이 필요하지 않습니다.

데모 약속방 코드: `DEMO24`. 기존 로컬 약속방 및 채팅 저장 키는 유지합니다.

## 주의
데모 지도·친구 위치·ETA는 실제 위치가 아닙니다. 실제 다중 사용자 채팅과 초대는 서버가 없어 지원하지 않습니다.

# 같이가 GATIGA — 3단계

HTML/CSS/JavaScript로 만든 서버 없는 모바일 웹앱입니다. **실제 GPS·지도·대중교통 API는 연결하지 않습니다.**

## 실행

1. ZIP을 압축 해제합니다.
2. `gachiga/index.html`을 Chrome/Edge에서 엽니다. 서버·설치 명령은 필요하지 않습니다.
3. 홈에서 `DEMO24`를 입력하거나 데모 약속방 카드를 눌러 상세 화면에 진입합니다.
4. `내 이동수단 설정` → 버스/지하철/도보/택시 선택 → 상세 설정 → 저장을 누릅니다.
5. 지도 마커 또는 참여자 카드를 선택하고 `도착 완료` 버튼으로 상태를 변경합니다. `5분 경과`로 가상 시간을 진행할 수 있습니다.
6. 새 약속방을 생성하고 상세 화면으로 이동하면 처음에는 참여자가 0명이며, 이동수단을 직접 설정한 후에만 `나`가 표시됩니다.

## 폴더 구성

- `index.html`: SPA 진입점
- `style.css`: 기존 민트 디자인 + 이동수단 UI
- `app.js`: 약속방·화면 전환·시뮬레이션
- `map-mock.js`: 가상 좌표 기반 목업 지도
- `arrival.js`: 2단계 계산 모듈 (호환용으로 유지)
- `transport.js`: 3단계 노선 예시 데이터와 ETA/정렬/진행률 계산
- `tests/`: Node 내장 테스트

## 동작과 제약

- 기존 저장 키 `gachiga.rooms.v1`을 변경하지 않아 같은 브라우저에서 이전 약속방을 유지합니다. 다른 폴더/브라우저 또는 파일 URL의 저장소 분리는 브라우저 정책에 따라 달라질 수 있습니다.
- `DEMO24`는 시연용 코드이며 다른 기기와의 실시간 참여는 불가능합니다.
- 시연방에는 수빈/지민/하영/소연의 **예시 참여자**가 있습니다. 새 약속방에 친구를 자동 추가하지 않습니다.
- 데모 약속방의 기준 시각은 2026-11-11 14:00, 새 약속방은 현재 기기 시각을 사용합니다. `5분 경과`는 가상 시간을 이동시키고 남은 시간을 5분 줄입니다.
- 남은 시간이 0이어도 자동으로 도착 완료되지 않습니다.
- 데모 이동수단 설정은 시연용 ‘나’ 참여자를 생성·수정합니다. 기존 예시 참여자 4명은 그대로 유지됩니다. 실제 본인 인증/친구별 권한은 없습니다.
- 교통 상태, 정류장, 역, 이동 진행률과 ETA는 전부 **예시 계산**입니다. 실제 경로/소요 시간과 무관합니다.
- `친구 초대`, `채팅` 버튼은 다음 단계 안내만 표시합니다. 개인정보 동의 팝업은 구현하지 않았습니다.

## 테스트

Node.js가 설치되어 있다면 `gachiga` 폴더에서 `node --test tests/*.test.js`를 실행합니다. 브라우저에서 모바일 보기(F12 → 기기 도구 모음)로 320px, 375px, 430px 폭을 확인합니다.

## 4단계: 개인정보 보호 및 데모 위치 공유

- 상세 화면의 **내 위치 공유 시작**을 누르면 동의 모달이 열립니다. 체크박스를 선택해야 시작할 수 있습니다.
- 동의 후에는 이 브라우저의 **데모 위치 마커 표시**만 활성화됩니다. GPS, 브라우저 위치 권한, 서버 요청은 없습니다.
- **위치 공유 중지**를 누르면 본인 마커와 ETA가 숨겨집니다. 다른 시연용 참여자는 가상 데이터이며 실제 사람의 동의가 아닙니다.
- **약속방 공유 종료**는 해당 브라우저의 그 방에서 모든 예시 마커와 ETA 표시를 종료합니다. 복구 버튼은 없습니다.
- 동의 여부와 방 종료 여부는 `gachiga.privacy.v1` 키에 **약속방별로** 저장됩니다. **공유 중 상태는 새로고침 시 무조건 꺼집니다**. 동의 기록은 남으므로 재시작 시 이전 동의를 확인하고 시작할 수 있습니다.
- 홈/약속방의 **개인정보 보호 안내**에서 프로토타입 안내를 확인할 수 있습니다. 법적 검토가 완료된 정책이 아닙니다.
- 초대 코드는 약속방 상세 화면에서 기본 숨김 상태이며 직접 펼쳐야 볼 수 있습니다. 약속방 생성 완료 화면은 기존 기능에 따라 코드를 보여줍니다.
- 채팅과 SNS 공유는 아직 미구현입니다. 실제 접근 권한, 사용자 인증, 암호화, 삭제/보존기간 관리도 없습니다.

### 4단계 테스트

`node --test tests/*.test.js` 실행. 브라우저에서 동의 거부, 체크박스 미선택, 동의 후 시작, 중지, 새로고침, 방 전환, 공유 종료를 직접 확인하세요.

## 5단계: 채팅 및 SNS 공유

- 약속방 상세의 **💬 채팅** 버튼에서 메시지를 입력하고 Enter 또는 전송 버튼으로 보낼 수 있습니다. 메시지는 약속방별 `localStorage`에 보관됩니다. 다른 브라우저나 기기로 동기화되지 않습니다.
- 시연 약속방 `DEMO24`에만 예시 대화가 기본 표시됩니다. 새 약속방은 빈 채팅으로 시작합니다.
- **📸 도착 현황 공유** 버튼에서 공유할 참여자를 체크한 후 9:16 미리보기를 확인합니다.
- **PNG 이미지 저장**은 Canvas API를 사용하여 1080×1920 이미지 파일을 생성합니다. **공유하기**는 지원 브라우저에서 Web Share API를 호출합니다. 미지원 환경에서는 이미지 저장을 이용하세요.
- 저장 및 공유 전 확인 창을 띄우며, 기본 별칭(친구 1 등)만 내보냅니다. GPS 좌표, 실제 이동 경로, 정확한 현재 위치, 초대 코드, 사용자 인증 정보는 SNS 데이터에 포함하지 않습니다. 다만 **약속 이름과 날짜·시간은 이미지에 포함되므로 민감한 내용이 없는지 확인하세요.**
- 본인의 도착 현황은 해당 약속방에서 데모 위치 공유가 켜져 있을 때만 공유 목록에 포함됩니다. 공유 종료된 방에서는 도착 현황을 내보낼 수 없습니다.
- 모바일 브라우저에서는 다운로드 파일이 브라우저 다운로드 폴더에 저장될 수 있습니다. 파일 공유는 HTTPS 또는 localhost 같은 보안 컨텍스트 및 브라우저 지원 여부에 따라 제한됩니다.

### 5단계 수동 확인 절차

1. `index.html`을 열고 `DEMO24`에 참여합니다. 채팅 화면에 예시 메시지 4개가 표시되는지 확인합니다.
2. 메시지를 입력하고 Enter를 누릅니다. 내 말풍선이 오른쪽에 표시되는지, 마지막 메시지로 스크롤되는지 확인합니다.
3. 새로고침하고 데모 약속방에 다시 들어가 보낸 메시지가 유지되는지 확인합니다.
4. 새 약속방을 만들고 채팅에 들어가 다른 방의 메시지가 나타나지 않는지 확인합니다.
5. 데모 약속방의 도착 현황 공유 화면에서 체크박스를 조정한 뒤 미리보기를 확인합니다.
6. 이미지 저장 버튼을 눌러 확인 창을 승인하고 다운로드된 PNG의 크기(1080×1920)를 확인합니다.
7. 공유하기를 눌러 지원 브라우저의 공유 메뉴가 열리는지 확인합니다. 지원하지 않으면 저장 안내가 표시됩니다.
8. 크롬 개발자 도구의 모바일 보기에서 320px, 375px, 430px 너비를 확인합니다.

### 테스트

`node --test tests/*.test.js` — 기존 1~4단계 테스트와 신규 채팅·SNS 데이터 테스트를 함께 실행합니다.

**주의:** 채팅 데이터와 데모 약속방은 서버에 저장되지 않습니다. 서버 인증, 접근 통제, 실시간 동기화, 데이터 암호화는 아직 구현되지 않았습니다.


## 6단계: 약속방 나가기 및 최종 시연
- 약속방 상세 맨 아래 **약속방 나가기**를 누르면 확인 팝업이 표시됩니다. 취소하면 아무것도 삭제되지 않습니다.
- 확인하면 해당 방을 내 약속방 목록에서 제거하고, 해당 방의 로컬 채팅/동의 기록을 삭제합니다. 다른 방의 데이터는 보존됩니다.
- 시연용 `DEMO24` 방을 나가면 이 브라우저에서 목록과 코드 입장이 숨겨집니다. 데모 방을 복구하려면 개발자 도구 콘솔에서 `localStorage.removeItem('gachiga.leftRooms.v1')` 후 새로고침하세요.
- 이 앱은 서버가 없는 로컬 프로토타입이므로 실제 카카오톡처럼 다른 사용자의 방에서 퇴장 처리하거나 알림을 전송하지 않습니다.
- 실제 GPS/교통 API/실시간 채팅/친구 초대/사용자 인증/서버 접근 제어는 구현되지 않았습니다.

### 발표 시연 순서
1. 홈에서 데모 약속방 `DEMO24` 입장 → 지도와 ETA 확인
2. 이동수단 선택 → 5분 경과 → 지각 예상과 도착 순서 확인
3. 위치 공유 동의 → 시작/중지 → 마커 표시 확인
4. 채팅 전송 → 새로고침 후 기록 확인
5. SNS 공유 미리보기 → 이미지 저장 (브라우저별 수동 확인 필요)
6. 새로운 약속방 생성 → 초대 코드 확인 → 약속방 나가기 → 취소/확인 비교

### 테스트
`node --test tests/*.test.js`로 계산/데이터 단위 테스트를 실행할 수 있습니다. 브라우저의 실제 PNG 저장, 모바일 레이아웃, 공유 시트는 기기에서 별도 확인해야 합니다.

## 친구 초대 및 채팅 시연 (추가)

- 홈에서 `DEMO24`를 입력하면 수빈·지민·하영·소연의 **시연용 그룹방**을 열 수 있습니다.
- 약속방 상세의 **친구 초대**를 누르면 초대 코드가 표시되고, **카카오톡·메시지 등으로 공유** 버튼이 기기의 기본 공유 메뉴(Web Share API)를 엽니다. 카카오톡이 설치되어 있고 공유 대상으로 제공되는 경우 선택할 수 있습니다. 인스타그램 DM은 운영체제·앱 지원 여부에 따라 공유 메뉴에서 선택하거나, **초대 문구 복사** 후 직접 붙여넣어야 합니다.
- 웹 서버에 게시된 앱은 `?invite=DEMO24`와 같은 초대 코드 포함 링크를 보낼 수 있습니다. 로컬 파일(`file://`)에서는 링크 대신 텍스트·코드를 공유합니다.
- **중요:** 현재는 서버·인증·실시간 채팅이 없으므로, 공유한 초대 코드로 **다른 기기에서 사용자가 만든 약속방에 입장하거나 채팅을 동기화할 수 없습니다.** `DEMO24`만 별도 시연 데이터로 모든 설치본에서 열 수 있습니다. 공유된 링크가 작동하려면 앱을 웹에 게시해야 합니다.
- 데모방 채팅에서 **데모 친구 답장 받아보기**를 누르면 가상의 친구 메시지가 로컬에 추가됩니다. 실제 친구가 보낸 메시지가 아니며 이름에 `· 데모`가 표시됩니다.
- 새 약속방에는 가짜 친구를 자동으로 추가하지 않습니다.

### 실제 친구와 채팅하려면
사용자 인증, 서버/실시간 데이터베이스, 약속방 참여 권한 검증, 채팅 저장·동기화 및 HTTPS 배포가 별도로 필요합니다.

## 추가 기능: 지도 한 줄 말풍선 + 우리 모임의 만남 도감

- 약속방 상세 화면의 지도 아래에서 **내 지도 프로필 한 줄 말풍선**을 작성하고 적용할 수 있습니다. 35자까지 저장되며 **내 위치 공유를 동의하고 시작한 동안에만** 내 마커 위에 표시됩니다. 실제 위치를 수집하지 않습니다.
- **📒 우리 모임의 만남 도감** 버튼으로 이동해 만난 날짜·장소·한 줄 추억·선택 사진을 등록할 수 있습니다. 기록은 약속방별 localStorage에 저장되며 횟수와 가장 자주 방문한 장소를 계산합니다.
- 데모 약속방 `DEMO24`에는 **예시 기록 3개**가 있으며, 새 약속방에는 예시 기록을 자동 추가하지 않습니다. 예시 기록은 시연용이라고 표시됩니다.
- 사진은 브라우저에서 최대 900px JPEG로 축소해 저장합니다. 사진이 크거나 저장 공간이 부족하면 등록에 실패할 수 있습니다. **다른 기기로 동기화되지 않으며 브라우저 데이터를 삭제하면 사라집니다.** 중요한 사진은 별도로 보관하세요.
- 단위 테스트: `node --test tests/*.test.js`.


## 최종 수정: 도착 현황 공유 제거 · 채팅 스크롤 · 지도 말풍선
- 약속방 상세의 **도착 현황 공유** 버튼을 제거했습니다. 기존 SNS 관련 소스 파일은 보존하여 다른 기능과의 충돌을 방지합니다.
- 채팅 목록의 각 말풍선이 줄어들지 않도록 고정해, 내용이 길어질 때 채팅 영역 안에서 마우스 휠과 터치 스크롤이 작동하도록 CSS를 보완했습니다.
- 지도 한 줄 말풍선은 Enter 또는 적용 버튼으로 저장하고, **입력창은 즉시 빈칸으로 초기화**됩니다. 저장된 내용은 위치 공유 중인 내 지도 마커에 계속 표시됩니다.
- 실제 친구 간 채팅 동기화는 여전히 제공하지 않습니다.


## 실제 GPS 기능 (추가)
- Windows: `start_windows.bat` 실행 후 `http://localhost:8765` 접속. Mac/Linux: 터미널에서 `./start_mac_linux.sh` 또는 `python3 -m http.server 8765`.
- `index.html` 파일을 직접 여는 file:// 환경에서는 위치 권한이 제한될 수 있습니다. 반드시 localhost 또는 HTTPS 사용.
- 약속방 > 내 위치 공유 시작 > 개인정보 동의 > `실제 GPS로 내 위치 표시` > 브라우저 위치 권한 허용.
- 실제 내 위치만 OpenStreetMap 지도에 표시합니다. 친구 마커/ETA/목적지 검색은 기존 데모 그대로입니다.
- **다른 사람에게 위치가 전송되지 않습니다.** GPS 좌표는 메모리에만 있고 localStorage나 앱 서버에 저장되지 않습니다.
- OpenStreetMap 타일을 가져오기 위해 인터넷이 필요하며, 지도 타일 서비스는 접속 IP와 지도 영역 등 요청 정보를 받을 수 있습니다.
- 위치 공유 중지, 약속방 나가기, 홈으로 이동, 탭 닫기 시 GPS 감시를 중지합니다.
- 모바일 다른 기기에서 이용하려면 HTTPS 배포가 필요합니다. 실제 친구 간 위치 공유는 인증/서버/접근통제 구현 후 가능합니다.


### 실제 지도 표시 수정
약속방 상세 화면은 GPS를 켜지 않아도 실제 OpenStreetMap 지도를 기본으로 보여줍니다. 초기 지도 중심은 성수동의 **예시 지역**이며 사용자 현재 위치가 아닙니다. 위치 공유에 동의하고 실제 GPS 버튼을 누르면 내 위치로 이동합니다. 인터넷 연결이 없거나 Leaflet CDN이 차단되면 데모 지도로 대체되며 안내 메시지가 표시됩니다. 다른 친구 위치는 실제 GPS가 아닙니다. 기존 서버를 종료하고 새 폴더에서 실행하세요.

## 카카오맵 연결 설정 (필수)

이 버전은 기존 OpenStreetMap 타일을 제거하고 **카카오맵 JavaScript SDK**로 교체했습니다.

1. [Kakao Developers](https://developers.kakao.com/)에서 애플리케이션을 생성합니다.
2. 카카오맵 사용에 필요한 플랫폼/도메인 및 지도 사용 설정을 카카오 개발자 콘솔의 현재 안내에 따라 등록합니다. 로컬 테스트 주소는 `http://localhost:8765`입니다. 필요한 경우 `http://127.0.0.1:8765`도 등록합니다.
3. **JavaScript 키**를 복사합니다. REST API 키가 아닙니다.
4. `kakao-config.js` 파일의 `window.GACHIGA_KAKAO_JS_KEY = '';` 따옴표 사이에 키를 붙여넣고 저장합니다.
5. `start_windows.bat`을 실행하고 브라우저에서 `http://localhost:8765`를 열어 확인합니다.
6. 지도에 오류가 나타나면 브라우저 개발자 도구의 Console에서 키/도메인 관련 오류를 확인합니다.

키가 없거나 도메인이 등록되지 않으면 **지도 배경을 표시할 수 없습니다**. 이 경우 오류 메시지를 보여주며, 차단된 OSM 타일로 자동 전환하지 않습니다. JavaScript 키는 브라우저에서 확인 가능한 공개형 키이므로 반드시 허용 도메인을 제한하세요. Admin 키는 절대 입력하지 마세요.

**현재 구현 범위:** 지도 배경과 내 GPS 위치만 실제입니다. 약속 장소를 텍스트로 입력해도 지도에서 자동 검색하거나 목적지 핀으로 표시하지 않습니다. 친구 위치와 ETA는 여전히 데모입니다.
